# ADR-023: M19 ComboBox + TabPanel + GridList

## Контекст
Мастер-промт §7.3 (DGS-паритет): выпадающий список, вкладки, таблица.
M18 дал контролы (checkbox/radio/slider/progressbar). M19 закрывает
"контейнерные" виджеты. Memo не нужен — Edit multiline (M15) покрывает.

## Решение

### 1. ComboBox
- **Структура**: node(PANEL, кликабельный) + label(TEXT, выбранное/
  placeholder) + arrow(TEXT "v") + dropdown(POPUP M17, root-узел, скрыт).
- **Dropdown = ui:popup** — dismiss по клику вне БЕСПЛАТНЫЙ (M17 popupStack).
  Клик по combobox при открытом dropdown → dismiss съедает клик → закрытие;
  следующий клик → open. Естественный toggle без дополнительной логики.
- **open()**: ВСЕГДА перестраивает rows (destroy old → create new) — cold
  path, актуальная ширина/состояние. Позиция — world (wx, wy + h) из
  storage.worldX/worldY (валидны после layout).
- **Items**: строки или {text=, value=}. getValue() → value выбранного.
- **onChange(idx, value)** — в setSelected (и в клике по пункту).

### 2. TabPanel
- **Структура**: node(PANEL) + bar(PANEL) + per-tab: btn(PANEL в bar) +
  label(TEXT) + page(PANEL, только выбранная видима).
- **addTab(title, children)** → возвращает page (PANEL) для прикрепления
  детей; или children-массив сразу. Первая вкладка auto-select.
- **selectTab(idx)**: hide старой page, show новой, перекраска кнопок.
- **_layoutTabs**: кнопки горизонтально, ширина = #title*7+16 (monospace).
- **removeTab**: пересчёт selected (сдвиг/пере-выбор первой).
- Children НЕ через attachChildren — только addTab (документировано).

### 3. GridList
- **Структура**: node(PANEL) + header(PANEL, колонки TEXT) + scroll
  (ScrollPanel M13, reparent под node через setParent).
- **Колонки**: addColumn(text, width) → _rebuildHeader (destroy/create
  labels, cold path). props.columns при создании.
- **Строки**: addRow(cells) → row(PANEL) + TEXT-ячейки, дети scroll content.
  Hover/selected цвета, click → selectRow → onSelect(idx, cells).
- **Скролл**: встроенный ScrollPanel — refresh() после addRow/clearRows
  (auto-measure по детям, M13).
- **clearRows**: destroy всех rows + release, refresh.

## Дефолты
- ComboBox: 150x26, itemH 24, placeholder "".
- TabPanel: 300x200, barH 24, active 0xFF3A6EA5, inactive 0xFF2A2A2A,
  page 0xFF222222.
- GridList: 300x200, headerH 20, rowH 22, row 0xFF222222, hover 0xFF2E4A6B,
  selected 0xFF3A6EA5, колонка width 100.

## Последствия
- Плюс: ComboBox использует popup (M17) — dismiss бесплатно, без дублирования.
- Плюс: GridList использует ScrollPanel (M13) — скролл/колесо/полосы бесплатно.
- Плюс: TabPanel pages — простые PANEL (видимость переключает culling M2).
- Минус: ComboBox rows перестраиваются на каждый open (cold path, O(items)).
- Минус: GridList без виртуализации (M13 virtualization не подключена;
  большие таблицы — M20+ через setVirtualProvider).
- Минус: GridList без сортировки/resize колонок/редактирования ячеек (M20+).
- Минус: TabPanel кнопки auto-ширина по monospace estimate.
- Минус: ComboBox dropdown позиция требует layout (renderFrame) — в игре
  всегда валидно, в тестах явный вызов.
