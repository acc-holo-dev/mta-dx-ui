# ADR-008: Anchors: 9 точек привязки, численные

## Контекст
UI-элементы часто привязываются к центру/краям (кнопка по центру панели, бейдж в углу).

## Решение
C.ANCHOR_TL/TC/TR/ML/MC/MR/BL/BC/BR = 0..8. Anchor задаёт, какая точка узла "приклеивается" к вычисленной позиции. Применяется после layout-mode, до margin. ANCHOR_TL (0) — без сдвига (default).

## Последствия
- Плюс: 9 якорей покрывают 99% UI-потребностей.
- Плюс: численный lookup (if/elseif по числу — быстро).
- Минус: только 2D; 3D-якорей нет (2D GUI — не нужно).
