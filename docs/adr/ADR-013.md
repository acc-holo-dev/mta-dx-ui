# ADR-013: M10 Production — Profiler OFF by default, zero overhead в проде

## Контекст
M9 завершён (оптимизации). M10 = production-ready: профайлер, debug, минимальный overhead. §50 ТЗ: "production: minimal overhead" — профайлер не должен замедлять игру, когда выключен.

## Решение
1. **Profiler (client/render/profiler.lua)** — ring buffer 120 кадров (≈2 сек @60fps), 9 фаз (total/anim/culling/layout/clip/builder/batcher/execute/flushClip). OFF by default (enabled=false). Включение: DXUI.toggleProfile() (chat command или console).
2. **Kernel:renderFrame** — if-check на profiler.enabled перед каждым mark (9 checks). Когда disabled: 9 if-checks (≈0.001ms) — zero overhead. Когда enabled: 9 clock calls + 9 table writes (≈0.1ms) — приемлемо для debug.
3. **Overlay (bootstrap.lua)** — DXUI-текстовый узел (NODE_TEXT), обновляется в onClientRender ПОСЛЕ renderFrame (отдельный handler, порядок addEventHandler = порядок вызова). Cold path: только при enabled.
4. **Clock injectable** — profiler.clock = fn (MTA: getRealTime()*1000, tests: fake).

## Последствия
- Плюс: zero overhead в проде (9 if-checks).
- Плюс: in-game profiling (не только bench/bench.lua).
- Плюс: avg-статистика (не только последний кадр).
- Минус: ring buffer 120 кадров = 120 tables × 9 numbers = ≈10KB (принято).
- Минус: overlay — DXUI-текстовый узел (зависит от DXUI, не независимый).
