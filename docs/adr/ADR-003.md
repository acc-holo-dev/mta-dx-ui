# ADR-003: Dirty-очередь за кадр: dirtyList без дублей

## Контекст
Узел может помечаться dirty многократно за кадр (setPosition 5 раз). Проходы должны увидеть его один раз.

## Решение
dirtyList — плоский массив (M9: по SLOT, не id), dirtyCount. markDirty: бит DIRTY_QUEUED (0x100) в маске = "уже в списке"; если не стоит — добавить в список и выставить бит. clearFrameDirty в конце кадра очищает очередь и все биты у узлов из списка (O(dirtyCount)).

## Последствия
- Плюс: O(1) markDirty, O(dirtyCount) обработка кадра.
- Плюс: без аллокаций (массив переиспользуется).
- Минус: порядок в списке = порядок первого markDirty (не важен для корректности layout — каскад обрабатывает поддерево целиком).
- Минус: destroy внутри кадра может оставить "дыру" slot — обработчик обязан проверять живость (eachDirtyLive / hasSlotDirty).
