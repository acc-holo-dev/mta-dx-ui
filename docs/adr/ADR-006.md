# ADR-006: Числовые константы в hot path, строки — только в публичном API

## Контекст
MTA Lua 5.1: табличные lookup по строке дороже, чем по числу. Hot path (каждый кадр) не должен аллоцировать и не должен искать по строкам.

## Решение
Все константы hot path — числа (C.DIRTY_*, C.FLAG_*, C.NODE_*, C.CMD_*, C.LAYER_*, C.EVENT_*). Строковые имена ("click", "panel") — только в публичном API (proxy:on("click"), ui:panel({...})), маппинг строка→число один раз при регистрации (cold path).

## Последствия
- Плюс: hot path — только числовые сравнения и битовые операции.
- Плюс: строки не аллоцируются в кадре (кроме текстовых команд — и те кэшируются в cmd-пуле).
- Минус: отладка сложнее (числа вместо имён) — debug-режим (C.DEBUG) печатает имена.
