# ADR-007: Layout: local→world каскад, LAY_ABS/REL/CENTER + anchor + margin

## Контекст
Узел описан локальными x/y + режимом. World-координаты зависят от world родителя. При движении родителя все потомки должны пересчитаться.

## Решение
storage.x/y — LOCAL (user API). storage.worldX/worldY — результат layout-прохода. Режимы: LAY_ABS (world = parent + local), LAY_REL (world = parent + local*parentWH), LAY_CENTER (world = parent center - w/2). Anchor (9 точек) сдвигает world после вычисления позиции. Margin mL/mT добавляется (mR/mB — для stretching, M8+). Padding родителя добавляется к позиции детей. Каскад: DIRTY_LAYOUT узел → пересчёт ВСЕГО поддерева (M9: итеративно, стек).

## Последствия
- Плюс: flexible layout без строк/объектов.
- Плюс: каскад O(поддерева), не O(всего UI).
- Минус: LAY_REL — float-арифметика (Lua 5.1 — double, OK).
- Минус: anchor+margin+padding — 3 слоя сдвигов; порядок зафиксирован (mode → anchor → margin → parent padding).
