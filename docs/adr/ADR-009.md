# ADR-009: Clip/Opacity/Blur: dirty-driven clip-глубина + регион, driver state

## Контекст
MTA DX9: dxDrawRectangle не имеет clip-параметра. Opacity/blur — тоже не нативные параметры. Нужна архитектура, которая в M5 даёт state (для драйвера), а в M8 — реальную реализацию (RT/shader).

## Решение
M5: FLAG_CLIP (0x10) на узле = "обрезаю детей по своим границам". Clip.update (dirty-driven): для каждого DIRTY_LAYOUT узла — findTopDirty (O(depth)) + countClipAncestors (O(depth)) + buildClipDepth (поддерево, записывает storage.clipDepth[slot] = число clip-областей выше). Дедупликация через topSet/topList (без аллокаций). M8: + storage.clipX/Y/W/H[slot] = world-регион ближайшего FLAG_CLIP-предка (nearestClipRect, O(depth), только когда dirty-top внутри клипа). Builder копирует depth+region в cmd-пул. StateCache: pushClip/popClip transitions (0↔1) + setOpacity/setBlur. M8 driver: RT Manager (ADR-011) + bitReplace alpha + 5-tap blur shader (image only).

## Последствия
- Плюс: M5 = state-only (mock-драйвер логит вызовы), M8 = real (RT/shader) — одна и та же data-модель.
- Плюс: dirty-driven — idle = zero work.
- Минус: nested clips M8 = single-level RT (innermost region); M10 = полный вложенный стек (clipX1..clipX4, до MAX_CLIP_DEPTH=4).
- Минус: blur для rect/text M8 = no-op (dxDrawRectangle/Text не принимает shader); M10 = RT-fallback (рендер в RT, затем draw RT с шейдером).
