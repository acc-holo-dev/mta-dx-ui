# ADR-021: M17 Tooltip + Popup + ContextMenu

## Контекст
Мастер-промт §7.3: "Tooltip: hover-подсказка; Popup: всплывающее окно;
ContextMenu: контекстное меню". M16 дал modal (overlay + focus lock + input
trap). M17 добавляет три "плавающих" виджета поверх существующего
Dispatcher/EventBus/Storage.

## Решение

### 1. Tooltip (proxy:setTooltip)
- **Универсальная фича**: метод на базовом proxy (любой узел может иметь
  подсказку), а не отдельный виджет.
- **Структура**: PANEL (тёмный фон) + TEXT (подпись) — ДЕТИ целевого узла.
  Дети → destroy-каскад сносит tooltip вместе с узлом (без утечки).
- **LAYER_TOOLTIP** (выше popup/modal/base) — setLayer переопределяет
  унаследованный слой (M16).
- **Показ**: mouseenter → позиция (0, h+4) ниже узла + setVisible(true);
  mouseleave → setVisible(false). Без задержки (delay — M18+).
- **setEnabled(false)** — tooltip не участвует в hit-test.
- **Размер** по длине текста (monospace estimate 7px/char, как Edit M15).
- **setTooltip(nil)** — скрыть и очистить.
- **Жизненный цикл**: proxy:release чистит _tooltip; proxyFactory (захват
  Proxy-инстанса в Proxy.new) создаёт tooltip-узлы из методов.

### 2. Popup (ui:popup)
- PANEL на LAYER_POPUP, скрыт по умолчанию. Методы show(x,y)/hide()/
  isShown()/toggle().
- **Dismiss по клику вне**: Dispatcher.popupStack — стек открытых popup
  { id, dismissFn }. onMouseDown: клик вне верхнего popup → pop + dismissFn
  (hide) + СЪЕДАЕТ клик (не доходит до фона).
- show() регистрирует dismissFn = hide(); hide() снимает (идемпотентно).
- _popupShown — флаг, чтобы show() не дублировал push.

### 3. ContextMenu (ui:contextmenu)
- Popup со списком пунктов: props.items = { { text=, onClick= }, ... }.
- Каждый пункт — PANEL (row) + TEXT (label), hover-highlight (mouseenter/
  mouseleave меняют цвет), клик → onClick + hide().
- Наследует PopupMethods (show/hide/isShown/toggle) — тот же dismiss.
- Типовое использование: node:on("mousedown", function(e)
  if e.button == "right" then menu:show(e.x, e.y) end end).

### 4. Dispatcher.popupStack
- pushPopup(id, dismissFn) / popPopup(id) / getTopPopup() / isInsidePopup(id).
- onMouseDown: popup-dismiss проверяется ПЕРЕД modal-trap (контекстное меню
  внутри modal: клик вне меню, но внутри modal → закрыть меню, не блокировать).
- Вложенные popup (подменю): isInsidePopup проверяет только ВЕРХНИЙ popup —
  клик внутри родительского меню, но вне подменю → закрыть подменю.

## Дефолты
- Tooltip: фон 0xE61E1E1E, текст 0xFFFFFFFF, размер 20px высота, 7px/char.
- Popup: LAYER_POPUP, скрыт, w/h из DEFAULTS.panel.
- ContextMenu: itemHeight 24, w 160, фон пункта 0xFF2A2A2A, hover 0xFF3A6EA5.

## Последствия
- Плюс: три плавающих виджета без изменения hot path — dismiss/показ только
  на input-события (cold path).
- Плюс: tooltip как дети узла — автоматический destroy-каскад, нет утечки.
- Плюс: popupStack переиспользует isDescendant (M16) — единый механизм.
- Минус: tooltip без задержки показа (мгновенно; delay — M18+).
- Минус: tooltip размер по monospace estimate (не точный font measurement).
- Минус: popup/contextmenu без анимации появления (M18+ — fade).
- Минус: contextmenu без подменю/разделителей/иконок (M18+).
- Минус: dismiss срабатывает на mousedown (клик вне съедается сразу), не на
  mouseup — стандартное поведение для меню.
