# ADR-018: M14 Edit — text input + focus system + keyboard

## Контекст
Мастер-промт §7.3: "Edit: ввод текста, курсор, selection, clipboard, focus;
Keyboard: onClientKey". M12/M13 дали composite-proxy + wheel + scrollbar.
M14 — текстовый ввод: focus system (глобальный focusedId), keyboard
routing (onClientKey → focusedId), Edit widget (text + cursor + special keys).

## Решение

### 1. Focus system (Dispatcher)
- **focusedId** — глобальный (Dispatcher), не per-widget.
- **setFocus(id)** — emit EVENT_BLUR на старый (если есть) + EVENT_FOCUS на
  новый (если id != NIL_ID). Повторный setFocus(существующий) — no-op.
- **getFocus()** — вернуть текущий focusedId.
- **onMouseDown** — автоматически setFocus(hit) (клик на узел = фокус).
  Клик мимо (hit == NIL_ID) снимает фокус.
- Focus не зависит от hover (можно сфокусировать без наведения).

### 2. Keyboard routing (Dispatcher.onKeyDown)
- **onKeyDown(key, state, text)** — эмитит на focusedId:
  - Если text непусто → EVENT_TEXT {text = text}.
  - Всегда → EVENT_KEY {key = key, state = state, text = text}.
- Если focusedId == NIL_ID — события игнорируются.
- MTA: addEventHandler("onClientKey", ...) → (key, state, mods, text) →
  kernel:onKeyDown(key, state, text).

### 3. Event constants
- **EVENT_FOCUS = 9** — узел получил фокус.
- **EVENT_BLUR = 10** — узел потерял фокус.
- **EVENT_TEXT = 11** — ввод текста (data: {text = string}).
- **EVENT_KEY = 12** — нажатие/отпускание клавиши (data: {key, state, text}).

### 4. Edit widget (composite-proxy)
- **Структура**: base (PANEL, фон) + text (TEXT, введённый текст) + cursor
  (thin PANEL, визуальная позиция). 3 узла, 1 handle.
- **State** (node._ed): text, placeholder, maxChars, readonly, cursor (0..#text),
  selStart, selEnd, hasFocus.
- **Keyboard**: EVENT_TEXT → append char at cursor; EVENT_KEY → special keys
  (BACKSPACE, DELETE, LEFT/RIGHT, HOME/END, ENTER, ESC).
- **Cursor**: визуальная позиция = cursor * 7px (monospace assumption).
  Не пересчёт layout, просто offset.
- **MaxChars**: cap на длину текста (0 = unlimited).
- **Readonly**: не принимать ввод, но фокус можно (для display-only).
- **Placeholder**: текст-подсказка (M14: не рендерится, M15: добавим).
- **Events**: onFocus/onBlur/onEnter (обвязка для user API).
- **setSize override**: пересчёт text/cursor positions.

### 5. Bootstrap wiring
- **onClientKey** → kernel:onKeyDown(key, state, text).
- Focus: mousedown → Dispatcher:setFocus(hit) (автоматически).

## Дефолты
- text = "", placeholder = "", maxChars = 0 (unlimited), readonly = false.
- Cursor после текста (cursor = #text).
- Focus: mousedown (стандартное поведение).

## Последствия
- Плюс: Focus system готов для M18 modal (focus lock = setFocus только на
  modal window children).
- Плюс: Keyboard routing через focusedId — один handler для всех Edit.
- Плюс: Composite-proxy (3 узла) — тот же паттерн, что Window/ScrollPanel.
- Минус: Selection (drag-select) — M15+ (M14: selStart/selEnd есть в state,
  но не используются).
- Минус: Clipboard (copy/paste) — M15+ (M14: нет CTR+C/V/A).
- Минус: Placeholder не рендерится (M14: только в state).
- Минус: Multiline Edit — M15+ (M14: single-line, UP/DOWN не работают).
- Минус: Cursor position — monospace assumption (7px/char), не точный
  font measurement (M15+).
