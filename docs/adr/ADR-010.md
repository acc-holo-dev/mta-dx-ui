# ADR-010: Animation: AnimationPool (SoA) + единый tick, без per-node таймеров

## Контекст
setTimer per node — запрещён архитектурой (тысячи таймеров = мусор + GC). Анимация должна быть data-driven.

## Решение
AnimationPool: SoA (field/from/to/startTime/dur/ease/nodeId) + activeList/activeIndexOf (swap-with-last O(1)) + freelist. proxy:animateTo(props, dur, ease) → pool:start (per property, interrupt from CURRENT value). dur<=0 = immediate snap (без pool entry). tick: animPool:update(now) ПЕРВЫЙ в renderFrame — пишет промежуточные значения в storage.x/y/w/h + DIRTY_POS (M9). clock — injectable (MTA: getRealTime()*1000, tests: fake). Easings: LINEAR/IN/OUT/IN_OUT (smoothstep) = 0..3, EASE_DEFAULT=IN_OUT.

## Последствия
- Плюс: O(active) на кадр, без таймеров, без аллокаций.
- Плюс: interruptible (animateTo перезаписывает from = current value).
- Минус: только x/y/w/h (4 поля); rotation/scale — future.
- Минус: clock — глобальный для пула (не per-node).
