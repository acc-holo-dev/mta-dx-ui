# ADR-022: M18 CheckBox + RadioButton + Slider + ProgressBar

## Контекст
Мастер-промт §7.3 (DGS-паритет): стандартные input/display-контролы.
M7 дал базовые виджеты (window/panel/button/label/image), M13-M17 — scroll/
edit/modal/tooltip/popup. M18 добавляет четыре контрола поверх composite-proxy.

## Решение

### 1. CheckBox / RadioButton (Toggle)
- **Структура**: node(PANEL, кликабельный) + box(PANEL 16x16) + mark(PANEL,
  виден при checked) + label(TEXT). mark/label/box — setEnabled(false)
  (визуальные, не кликабельные); клик по node → toggle.
- **ToggleMethods**: setChecked/isChecked/toggle/_renderToggle/destroy.
- **RadioButton** наследует ToggleMethods (metatable __index), переопределяет
  setChecked: при выборе снимает остальные в группе.
- **Группа**: props.group (строка) → общий список в UI._radioGroups[group].
  Каждый radio хранит _groupList (ссылку на общий список). destroy удаляет
  себя из группы.
- **Клик**: checkbox → toggle; radio → setChecked(true) (клик по выбранному
  radio — no-op, не снимается). onChange(checked) — в click-обработчике.

### 2. ProgressBar
- **Структура**: node + track(PANEL, фон) + fill(PANEL, ширина = frac * w).
- **ProgressMethods**: setValue/getValue/setRange/_renderProgress/setSize/destroy.
- frac = (value - min) / (max - min), clamp 0..1; guard range <= 0 → frac 0.
- setSize override: resize track + re-render fill.

### 3. Slider
- **Структура**: node + track + fill + thumb(PANEL, draggable, z=2 поверх fill).
- **SliderMethods**: setValue/getValue/setRange/_renderSlider/setSize/destroy.
- **Drag thumb**: Dispatcher:beginDrag (M12) с delta-подходом — startFrac +
  dx/trackLen, БЕЗ world-координат (работает для вложенных slider'ов).
  onChange(value) — в drag-колбэке.
- **Горизонтальный**; вертикальный — M19+.

### 4. Общее
- Все — composite-proxy (1 handle → несколько узлов), destroy-каскад чистит
  части, release возвращает proxy в пул.
- Нет новых NODE-типов/событий/слоёв — всё на PANEL/TEXT + click/mousedown.

## Дефолты
- checkbox/radio: 120x24, box 16x16, mark 10/8, box 0xFF333333, mark
  0xFF00CC00 (check) / 0xFF3399FF (radio).
- progressbar/slider: 200x16, track 0xFF333333, fill 0xFF00CC00, thumb
  0xFFDDDDDD, thumbW 10.
- min=0, max=100, value=0.

## Последствия
- Плюс: четыре контрола без изменения hot path (toggle/drag — cold path).
- Плюс: radio-группа через общий список (O(группа) на выбор, cold path).
- Плюс: slider drag без world-координат (delta-подход) — работает вложенным.
- Минус: slider только горизонтальный (вертикальный — M19+).
- Минус: slider без click-to-jump (клик по track не двигает thumb; M19+).
- Минус: checkbox/radio mark — квадрат (не настоящая галочка/круг; M19+ —
  текстовые глифы или кастомный рендер).
- Минус: нет disabled-состояния (серый вид) — только setEnabled(false) для
  hit-test (M19+).
