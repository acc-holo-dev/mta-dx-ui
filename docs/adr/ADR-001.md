# ADR-001: Dirty-bitmask invalidation: один бит на подсистему

## Контекст
Retained-mode GUI: каждый кадр должен перерисовывать только то, что изменилось. Полное дерево на кадр — O(n) всегда, недопустимо (§8 ТЗ: zero-work idle frame).

## Решение
Каждый узел несёт битовую маску dirty (storage.dirty[slot]). Каждый бит инвалидирует РОВНО одну подсистему конвейера: DIRTY_LAYOUT (layout), DIRTY_RENDER (builder/cmd-пул), DIRTY_VISIBILITY (culling), DIRTY_CONTENT (текст/текстура), DIRTY_TRANSFORM (позиция), DIRTY_CHILDREN (состав), DIRTY_INPUT (hit-test). Проходы читают только свой бит. M9: DIRTY_POS = LAYOUT|TRANSFORM|RENDER — слитый бит для setPosition/setSize/anim (все три подсистемы обязаны отработать).

## Последствия
- Плюс: O(dirty) на кадр, idle = zero work.
- Плюс: проходы независимы — легко профилировать по биту.
- Минус: биты надо держать согласованными (setPosition → DIRTY_POS, а не только RENDER).
- Минус: DIRTY_QUEUED — служебный бит в той же маске (0x100), не путать с публичными.
