# ADR-004: RT-кэширование: FLAG_STATIC / FLAG_PINNED_RT

## Контекст
Многие UI-блоки статичны (фоновые панели, HUD-рамки). Перерисовывать их каждый кадр — мусорная работа. DX9 позволяет рендерить в offscreen RT и потом тянуть RT как текстуру.

## Решение
Зарезервированы флаги FLAG_STATIC (0x04) — hint для auto-RT-кэша, и FLAG_PINNED_RT (0x08) — явный pinned RT. Реализация RT-кэша — M9/M10 (сейчас RT Manager владеет RT только для clip, ADR-011). Критерий auto: узел без DIRTY_* N кадров подряд + FLAG_STATIC.

## Последствия
- Плюс: статичные блоки = 0 draw calls после первого кадра.
- Минус: RT — дорогая GPU-память; нужен LRU-пул и лимит.
- Минус: dirty-инвалидация RT — каскадная (ребёнок dirty → RT родителя невалиден).
