# ADR-024: M20 Polish — opacity-анимации, tooltip delay, modal auto-focus, slider

## Контекст
M19 закрыл контейнерные виджеты. M20 — финальная полировка UX + два
механизма, которых не хватало: fade-анимации (ANIM_OPACITY) и отложенные
колбэки (tooltip delay) без setTimer (ADR-010).

ВАЖНО (история): при проверке выяснилось, что секции M15-билдер Edit,
M17 (Popup/ContextMenu) и M18 (контролы) отсутствовали в ui.lua — потеряны
в ранних сессиях (git-истории нет). Восстановлены по ADR-018/019/021/022
в рамках M20. ComboBox (M19) ломался: self:popup не существовал.

## Решение

### 1. ANIM_OPACITY (AnimationPool, storage, proxy)
- C.ANIM_OPACITY = 5; storage.animOpacity[slot] — 5-я колонка pool-слотов.
- AnimationPool: applyOpacity(s, id, slot, v) — значение + FLAG_OPACITY
  (как proxy:setOpacity), DIRTY_RENDER (НЕ DIRTY_POS — layout не затронут).
- start/stop/update обрабатывают поле 5; animateTo({opacity=}) + isAnimating
  учитывают его.
- opacity НЕ каскадится (builder.lua: pool.opacity[cmdSlot] =
  storage.opacity[nodeSlot]) — fade поддерева обходит каждый узел отдельно
  через animPool:start (raw id, без proxy) — fadeSubtree (ui.lua).

### 2. Kernel:schedule — отложенные колбэки без setTimer
- self.clock = clockFn (тот же, что у animPool); self.timers = {}.
- Kernel:schedule(delayMs, fn) — выполнение в renderFrame (_runTimers,
  ПЕРЕД animPool:update). Отмена не поддерживается — колбэк сам проверяет
  актуальность (idempotent по времени: now >= at).
- Tooltip delay (proxy:setTooltip): mouseenter -> schedule(400ms) ->
  показать только если kernel.dispatcher.hoveredId == targetId и узел жив
  (isAlive guard против use-after-destroy в async).
- Proxy.new принимает kernel 4-м аргументом (только для schedule).

### 3. Modal auto-focus (setModal)
- kernel.focusables — реестр фокусируемых id (Edit регистрирует при
  создании, снимает при destroy).
- setModal(true): findFirstFocusable(k, self.id) — DFS по поддереву;
  фокус на первый Edit, иначе на окно (keyboard терпит внутри modal).
- Overlay fade-in: setOpacity(0) + animateTo({opacity=255}, 150, EASE_OUT).
  Цвет overlay несёт альфу 0x80 — opacity узла отдельный множитель 0->255.

### 4. Popup fade-in
- PopupMethods:show -> fadeSubtree(k, self.id, 0, 255, 100, EASE_OUT).
- Fade-out не делаем: hide мгновенный (dismiss по клику вне).

### 5. Slider
- click-to-jump: mousedown на node, e.target ~= thumb.id — value = frac
  от курсора (worldX трека), снова через beginDrag не нужно (разовый).
- orientation="v": вертикальная разметка (fill по высоте, thumb вдоль Y,
  drag по py).

## Восстановление M15-tail/M17/M18 (по ADR-018/019/021/022)
- Edit builder: composite base+text+ph+cursor, sel-пул (freelist),
  mousedown->focus+caret+drag-select, text/key события, focus/blur.
  maxChars = props.maxLength (совместимо с _renderText).
- Popup: LAYER_POPUP, скрыт; show(x,y)/hide()/isShown()/toggle() через
  Dispatcher.popupStack; dismissFn = hide; _popupShown guard.
- ContextMenu: popup + rows (hover-highlight, клик -> onClick + hide).
- CheckBox/RadioButton: box+mark+label; radio-группа через общий список
  UI._radioGroups[group] (клик по выбранному radio — no-op).
- ProgressBar: track+fill, frac clamp.
- Slider: track+fill+thumb, drag thumb — beginDrag delta-подход (ADR-022),
  thumbSize, vertical в M20.

## Дефолты
- MODAL_FADE_MS = 150, POPUP_FADE_MS = 100, TOOLTIP_DELAY_MS = 400.
- Slider thumbSize = 10 (SLIDER_THUMB_MIN).
- checkbox/radio: box 16x16, mark 10x10 check 0xFF00CC00 / 8x8 radio
  0xFF3399FF. progressbar/slider: track 0xFF333333, fill 0xFF00CC00,
  thumb 0xFFDDDDDD.
- Edit: w 160 h 24 (multiline 64), cursor 0xFFFFFFFF z=30.

## Последствия
- Плюс: fade без изменения hot-пути рендера (анимация в AnimationPool,
  каскад обхода не в hot frame).
- Плюс: schedule без setTimer — свойство единого clock держится (ADR-010).
- Плюс: tooltip delay актуален (hoveredId check) — нет отмены/утечек.
- Плюс: modal auto-focus — первый Edit готов к вводу сразу.
- Минус: schedule-колбэки — table.remove, cold path (редкие).
- Минус: fade-out popup нет (мгновенный hide) — сознательно.
- Минус: tooltip delay проверяет hoveredId — при destroy во время delay
  колбэк no-op (isAlive/idToSlot guard).
- Минус: восстановление M15-18 было вручную по ADR — добавочный риск.
