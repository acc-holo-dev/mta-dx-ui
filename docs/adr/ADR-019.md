# ADR-019: M15 Edit 2.0 — selection + clipboard + multiline + placeholder

## Контекст
M14 дал базовый Edit (text + cursor + focus + keyboard). Мастер-промт §7.3
требует полный текстовый ввод: "Edit: ввод текста, курсор, selection,
clipboard, focus". M15 закрывает оставшиеся пункты: selection (drag-select),
clipboard (copy/paste/cut), multiline, placeholder render.

## Решение

### 1. Selection (anchor/cursor модель)
- **ed.selAnchor** (якорь) + **ed.cursor** (фокус). Выделение = [min, max),
  0-based. selStart/selEnd — производные, пересчитываются в _syncSel.
- **Typing replaces selection**: _replaceSel(text) вырезает [selStart, selEnd)
  и вставляет текст, cursor встаёт в конец вставки.
- **Shift-навигация**: arrow_l/r/u/d, home/end с mods "shift" двигают cursor
  БЕЗ сброса selAnchor (расширение выделения); без shift — collapse.
- **Drag-select**: mousedown (left) → anchor = cursor = charAt(screen→local),
  затем Dispatcher:beginDrag (M12) захватывает движение до mouseup, каждый
  move обновляет cursor. Экранные коорд → локальные через node:getPosition()
  (world) минус EDIT_PAD. charAt: row = floor(ly/LINE_H), col = round(lx/CHAR_W).
- **Визуализация**: пул ed.selNodes (PANEL, z=5, полупрозрачный синий). По
  одной панели на выделенную строку; лишние скрываются (не уничтожаются —
  freelist-принцип, тот же что Storage/ProxyPool).

### 2. Clipboard (виртуальный буфер)
- **kernel.clipboard** — строка. MTA не даёт системный clipboard из
  клиентского Lua, поэтому виртуальный буфер на уровне kernel (copy/paste
  между полями того же kernel).
- **ctrl+a** — select all; **ctrl+c** — copy selection; **ctrl+x** — cut;
  **ctrl+v** — paste (replace selection / insert at cursor).
- **Dispatcher guard**: ctrl-комбо НЕ эмитят EVENT_TEXT (иначе ctrl+v
  вставил бы и "v", и буфер). mods передаётся в EVENT_KEY.

### 3. Multiline
- **props.multiline** (default false). ENTER вставляет "\n" (multiline) или
  вызывает onEnter (single-line).
- **UP/DOWN** — навигация по строкам с goalCol (запоминает колонку при
  вертикальном движении, как в нативных редакторах).
- **HOME/END** — начало/конец ТЕКУЩЕЙ строки (не всего текста).
- Текст-узел растёт по высоте (#lines * LINE_H); \n рендерится нативно
  dxDrawText.

### 4. Placeholder render
- **parts.ph** — TEXT-узел (серый, z=19), виден когда text == "" и
  placeholder ~= "" и НЕ в фокусе. При фокусе скрывается (стандарт).

### 5. Ключи — строки MTA key map
- M14 использовал числовые коды; M15 переходит на СТРОКИ MTA key map
  ("backspace", "delete", "arrow_l", "arrow_r", "arrow_u", "arrow_d",
  "home", "end", "enter", "escape", "a".."z"). Dispatcher.onKeyDown(key,
  state, mods, text) — key строка, mods строка ("ctrl"/"shift"/"").

### 6. Дополнительный API
- setSelection(start, finish) / getSelection() → start, end.
- onChange(fn) — колбэк на изменение текста (ed.changeCbs).
- onEnter(fn) — теперь SET ed.onEnterCb (не подписка на key-событие).

## Дефолты
- multiline = false, readonly = false, maxChars = 0 (unlimited).
- CHAR_W = 7px, LINE_H = 15px (monospace assumption), PAD_X = 4, PAD_Y = 2.
- Selection color 0x663399FF, placeholder 0xFF888888, cursor 0xFF00FF00.

## Последствия
- Плюс: полный DGS-паритет текстового ввода (selection/clipboard/multiline).
- Плюс: freelist-пул для selection highlight (не создаём/уничтожаем per change).
- Плюс: виртуальный clipboard — copy/paste между полями без системного API.
- Минус: CHAR_W/LINE_H — monospace assumption, не точный font measurement
  (M16+ — реальный dxGetTextWidth).
- Минус: нет undo/redo (M16+).
- Минус: нет горизонтального скролла длинных строк (clip по ширине узла).
- Минус: multiline без внутреннего скролла (авто-рост высоты; M16+ — scroll).
- Минус: drag-select требует renderFrame (world-координаты) — в игре layout
  идёт каждый кадр, в тестах нужно явно вызвать renderFrame.
